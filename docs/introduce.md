# REDMI Watch 5 eSIM Unofficial ROM

本项目为红米手表 5 eSIM 版提供非官方定制 ROM，旨在优化和增强原厂固件体验。

## 特性

- **更好的字体** — 替换系统字体，提升显示效果
- **更多应用插槽** — 增加可安装的自定义应用（.rpk）数量
- **多主题可选** — 提供 Theme1 / Theme2 / Theme3 三种不同风格的固件包

## ROM 内容

每个主题包含以下固件分区：

| 分区 | 说明 |
|------|------|
| `vela_system.bin` | 系统分区 |
| `vela_app.bin` | 应用分区 |
| `vela_font.bin` | 字体分区 |
| `vela_watchface.bin` | 表盘分区 |
| `vela_quickapp.bin` | 快应用分区 |
| `vela_vendor.bin` | 厂商分区 |
| `vela_dsp.bin` | DSP 固件 |
| `vela_sensor.bin` | 传感器固件 |
| ... | 及其他必要分区 |
